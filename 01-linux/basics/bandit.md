# OverTheWire: Bandit Writeup

## Level 0 -> 1
- **Команда:** `cat readme`
- **Суть:** `cat` выводит содержимое файла в терминал.

## Level 1 -> 2
- **Команда:** `cat ./-`
- **Суть:** Для файлов с именем `-` нужен относительный путь `./-`.

## Level 2 -> 3
- **Команда:** `cat "spaces in this filename"`
- **Суть:** Пробелы в именах файлов экранируются кавычками.
