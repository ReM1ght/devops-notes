# OverTheWire: Bandit Writeup

## Level 0 -> 1
- **Команда:** `cat readme`
- **Суть:** `cat` выводит содержимое файла в терминал.

## Level 1 -> 2
- **Команда:** `cat ./-`
- **Суть:** Для файлов с именем `-` нужен относительный путь `./-`.

## Level 2 -> 3
- **Команда:** `cat "spaces in this filename"`
- **Суть:** Пробелы в именах файлов экранируются кавычками.

## Level 3 -> 4
- **Команда:** `ls -la` → `cat ./...Hiding-From-You`
- **Суть:** Для отображения скрытых файлов используется `ls -la` затем читается через `cat`. (`-a` = показать все файлы ; `-la` = показать все файлы детально)

## Level 4 -> 5
- **Команда:** `file ./*` → `cat ./-file07`
- **Суть:** `file ./*` определяет тип файлов в папке, чтобы найти читаемый текст (`ASCII text`).

## Level 5 -> 6
- **Команда:** `find . -type f -size 1033c ! -executable` → `cat ./maybehere07/.file2`
- **Суть:** `find .` ищет файлы в текущей папке по фильтрам: `-type f` (файл), `-size 1033c` (1033 байта), `! -executable` (не исполняемый).

## Level 6 -> 7
- **Команда:** `find / -user bandit7 -group bandit6 -size 33c | grep -v "Permission denied"` → `cat /var/lib/dpkg/info/bandit7.password`
- **Суть:** `find /` ищет по всему диску. `| grep -v "Permission denied"` фильтрует ошибки доступа, исключая строки с запретом чтения.

## Level 7 -> 8
- **Команда:** `grep "millionth" data.txt`
- **Суть:** `grep` ищет указанное слово в файле и выводит всю строку, содержащую это слово.

## Level 8 -> 9
- **Команда:** `sort data.txt | uniq -u`
- **Суть:** `sort` группирует одинаковые строки вместе, а `uniq -u` фильтрует их, выводя только единственную уникальную строку.

## Level 9 -> 10
- **Команда:** `strings data.txt | grep "=="`
- **Суть:** `strings` извлекает из бинарного файла читаемый текст, а `grep "=="` отбирает строки, содержащие знаки равенства.

## Level 10 -> 11
- **Команда:** `base64 -d data.txt`
- **Суть:** `base64 -d` декодирует данные из формата Base64 обратно в исходный текст.

## Level 11 -> 12
- **Команда:** `cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'`
- **Суть:** `tr` заменяет каждый символ первого диапазона на символ из сдвинутого диапазона, расшифровывая ROT13.
